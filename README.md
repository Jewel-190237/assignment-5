# Assignment 5 - Bus Ticket Booking System

A modern, responsive bus ticket booking website built with HTML, Tailwind CSS, and JavaScript. This project provides a complete bus booking experience with seat selection, pricing, and confirmation.

## Features

- Interactive bus seat selection
- Responsive design that works on all devices
- Modern UI/UX with smooth animations
- Clean and professional booking layout
- Mobile-first approach
- Tailwind CSS for rapid styling
- JavaScript for dynamic functionality
- Multiple pages: Home and Success
- Real-time price calculation
- Coupon code support

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (Interactive Booking)
- Responsive Design
- Modern CSS Flexbox/Grid

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Jewel-190237/assignment-5.git
   ```

2. Open the project folder:
   ```bash
   cd assignment-5
   ```

3. Open `index.html` in your browser to view the booking system.

## How to Use

1. Select your departure and destination stations
2. Choose your travel date
3. Select available seats from the bus layout
4. Enter passenger information
5. Apply coupon code if available (NEW15, FLAT20)
6. Complete booking and view confirmation

## Booking Features

- **Seat Selection**: Click on available seats to select them
- **Price Calculation**: Real-time price updates based on selected seats
- **Coupon Support**: Apply discount codes for special offers
- **Station Selection**: Choose from multiple departure/destination points
- **Confirmation Page**: View booking details after successful purchase
